# ADR-001: Архитектура MVP EventHub UZ

- Статус: принято для MVP
- Версия: 0.5
- Решение: mobile-first модульный монолит на Next.js, PostgreSQL/Supabase с RLS для production-данных, PWA вместо отдельного мобильного приложения, изолированный контейнер для развертывания.

Полная утвержденная версия с тремя архитектурными вариантами, характеристиками ролей, guardrails, роадмапом без сроков и пользовательскими последствиями хранится рядом в `ADR-001_EventHub_UZ_MVP_Architecture_v0.5.docx`.

## Граница текущего релиза

Каталог, карточки поставщиков, свежесть данных, shortlist, свадебный чек-лист, заявки и их статусы, кабинет поставщика, Excel-импорт в черновики, модерация, блокировки и аудит. Заявка не является бронью, договором или оплатой. Публичного рейтинга нет до принятия антифрод-правил.
