# ADR-001: Архитектура MVP Marosim

- Статус: принято для MVP
- Версия: 0.5
- Решение: mobile-first модульный монолит на Next.js, PostgreSQL/Supabase с RLS для production-данных, PWA вместо отдельного мобильного приложения, изолированный контейнер для развертывания.

Актуальная версия с тремя архитектурными вариантами, характеристиками ролей, guardrails, роадмапом без сроков и пользовательскими последствиями хранится рядом в `ADR-001_Marosim_MVP_Architecture_v0.6.docx`. Версия `v0.5` сохранена как история до выбора названия Marosim.

## Граница текущего релиза

Каталог, карточки поставщиков, свежесть данных, shortlist, свадебный чек-лист, прямые диалоги клиента с поставщиком, кабинет поставщика, Excel-импорт в черновики, модерация, блокировки и аудит.
